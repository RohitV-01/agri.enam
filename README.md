# agri.enam

e-NAM (National Agriculture Market) web application built with CodeIgniter.

## Requirements

- PHP 5.6+ (PHP 7.x recommended)
- MySQL/MariaDB
- Apache with mod_rewrite (XAMPP supported)

## Setup

1. Clone the repository into your web server document root.
2. Copy `application/config/database.php.example` (if present) or create `application/config/database.php` with your database credentials (this file is gitignored).
3. Ensure `application/cache`, `application/logs`, and `uploads` are writable.
4. Configure your virtual host or access via `http://localhost/web/`.
